# Loja de Informática

Projeto da 1ª avaliação prática de PRW2.

## Funcionalidades

- Cadastro de produtos
- Seção do produto em lista suspensa
- Marca do produto em lista suspensa
- Nome e preço
- Seleção entre novo e usado
- Gerenciamento de estado com `useState`
- Renderização dinâmica com `map`
- Filtragem dos produtos por seção com `filter`


## Executar

```bash
npm install
npm run dev
```
